# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **NovelCraft**, please do NOT open a public issue.

Instead, please send an email to the repository maintainer with:
1. Description of the vulnerability.
2. Steps or proof-of-concept to reproduce the vulnerability.
3. Potential impact on local Ollama / FastAPI endpoints.

We will review the vulnerability report, provide an initial response within 48 hours, and work on a patch promptly.
